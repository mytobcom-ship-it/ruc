회전각 계산·표기 기준

계산

  1. ST_LINK에서 NODE_ID로 향하는 진입 접선을 구한다.
  2. NODE_ID에서 ED_LINK로 향하는 진출 접선을 구한다.
  3. atan2(cross, dot)로 -180°~+180° signed angle을 계산한다.

EPSG:5186에서 +각도=좌회전, -각도=우회전으로 표기한다.

형상 분류용 임계값

|θ| ≤ 30° → STRAIGHT |θ| ≥ 150° → UTURN_LIKE 30° < θ < 150° → LEFT -150° < θ < -30° → RIGHT

현재 BinaryMaker.cpp의 기준과 같은 분석용 값이며 공식 TURN_TYPE 규격은 아니다.

권장: official_turn_type, turn_oper, geometry_turn, turn_angle_deg를 분리한다. `011`을 `11`로 변환하지 말고 3자리 원본 코드를 유지한다.
