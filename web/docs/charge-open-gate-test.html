개방식(OPEN) 임시 게이트 테스트 — DDL·데이터

"톨게이트처럼 임시로 개방식 도로에 게이트 ID를 부여해 사용" 방식을 테스트하기 위한 최소 구성입니다. base_roadlink → base_tollgate(gate_div=M) → base_tollfare 3개 테이블만 있으면 되고, 전국 표준노드링크(road_link)나 base_mapinfo에는 손댈 필요가 없습니다 (개방형·폐쇄형 판정은 base_tollgate 계열만 사용 — charge-tables.html I-4 참고).

이 문서의 DDL은 실제 pg_dump가 아닙니다. doc/RUC_과금DB_스키마_기준선_v1.0.md(2026-08-07, pg_description 코멘트 조사 기반)를 근거로 재구성한 것으로, 추정 표시된 항목(정밀도·인덱스·CHECK 제약)은 실제 운영 DB에 존재하는지 확인되지 않았습니다. 원격 DB(59.11.91.162) 접속이 복구되면 pg_dump --schema-only로 대조검증 후 v1.1 델타 문서에 반영할 것.

0. 개요·목적

로컬에 원격 DB(59.11.91.162)와 동일 구조의 ruc 테스트 DB를 구성해, 개방식 게이트 통과 판정 흐름을 원격 접속 없이도 테스트할 수 있게 하는 것이 목적입니다. 실행 순서: base_roadlink.sql → base_tollgate.sql → base_tollfare.sql → base_open_gate_test_data.sql. 
psql -U postgres -d ruc -f roadnet/sql/base_roadlink.sql
psql -U postgres -d ruc -f roadnet/sql/base_tollgate.sql
psql -U postgres -d ruc -f roadnet/sql/base_tollfare.sql
psql -U postgres -d ruc -f roadnet/sql/base_open_gate_test_data.sql

speed_limit_kmhnumeric(6,1) 추정NULL—제한속도(km/h) — road_kind=3 판정 기준
use_ynchar(1)'Y'—Y 사용 / N 미사용
